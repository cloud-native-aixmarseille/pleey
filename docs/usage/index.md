Start guidance from the corresponding screen. Completed guides can be replayed.

## Who does what

| Role                       | Typical actions                                                |
| -------------------------- | -------------------------------------------------------------- |
| Player                     | Join a party, answer stages, follow standings                  |
| Host                       | Launch a party, invite players, run stages and wrap up results |
| Organization member        | Create and edit quiz and prediction content                    |
| Organization owner/manager | Manage organization, projects, and member access               |

## Vocabulary

- **Game**: prepared content, either quiz or prediction.
- **Stage**: one question or prediction prompt.
- **Party**: one live session of a game, identified by a join code.
- **Organization / Project**: workspace containers for games and access control.
