# Settings and shortcuts

## Preferences menu

Open the account menu in the header. The preferences section holds:

- **Language**: the **EN** / **FR** button switches between English and French. The choice is stored in your browser. On first visit, French is used when your browser is in French, English otherwise. Password reset emails use the same language.
- **Light** / **Dark**: switches the color scheme.
- **Shortcuts**: opens the keyboard shortcuts help.
- **Version**: the version of Pleey you are using.
- **Feedback**: a link to report a bug or suggest a feature. It is shown only when your Pleey administrator configured it.

## Keyboard shortcuts

Everywhere:

| Key | Action |
| --- | --- |
| `?` | Open the shortcuts help |
| `U` | Open or close the account menu |
| `Esc` | Close menus and dialogs |

Host, during a party:

| Key | Action |
| --- | --- |
| `R` | Reveal result |
| `N` | Next stage |
| `P` | Pause or resume |
| `Shift+B` | Previous stage |
| `Shift+R` | Restart stage |
| `Shift+L` | Back to lobby |
| `Shift+E` | End party |

Player, during a question:

| Key | Action |
| --- | --- |
| `1` to `9` | Pick that answer |
